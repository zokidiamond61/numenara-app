# Numenara

Numerology app by **Nan Numero** (publisher: Barbara Tot). Design & development: Zorica Kolundžija.

- `www/index.html` – the whole app (bilingual EN/SR)
- `assets/` – icon and splash images
- `.github/workflows/build.yml` – builds the signed Android App Bundle (`.aab`) for Google Play and an `.apk` for testing

## How to get the app file
Open the **Actions** tab → latest green run → download **Numenara-N** at the bottom.
